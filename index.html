Kubernetes : Commandes et Gestion

Ressource de révision basée sur les notes de cours

1. Environnement et Outils

  • labs-config.conf : Contient les certificats pour authentifier la connexion.
  • labs-config.sh : Script pour configurer l'environnement. À exécuter avec source labs-config.sh.
  • kubectl : Outil officiel (utilise ~/.kube/config). Test de connexion : kubectl cluster-info.
  • k9s : Interface graphique TUI dans le terminal pour la surveillance.

2. Gestion des Pods

  • Pod : Plus petite unité logique, contient un ou plusieurs conteneurs.
  • États : Pending, Running, Succeeded, Failed.
  • kubectl apply -f ns-login.yaml : Crée l'espace de nom.
  • kubectl apply -f nginx-pod.yaml : Déploie le pod.
  • kubectl get pods -n ns-rlaurens : Liste les pods.
  • kubectl describe pod nginx-pod -n ns-rlaurens : Affiche les détails et événements.
  • kubectl get pod nginx-pod -n ns-rlaurens -o jsonpath='{.spec.containers[*].name}' : Isole le nom du conteneur.
  • kubectl exec -it nginx-pod -n ns-rlaurens -- /bin/bash : Ouvre un shell interactif.
  • kubectl delete pod nginx-pod -n ns-rlaurens : Supprime le pod.

3. ReplicaSet & Deployment

  • ReplicaSet : Maintient un ensemble stable de Pods.
  • Deployment : Gère les ReplicaSets, permet le Rollback et le Rolling Update.
  • kubectl get pods -n ns-rlaurens -w : Surveiller en temps réel.
  • kubectl scale deployment dep-nginx --replicas=4 -n ns-rlaurens : Scale UP (augmente la charge).
  • kubectl set image deployment/dep-nginx nginx=nginx:1.16.1 --record=true : Mise à jour de l'image (historisée).
  • kubectl rollout undo deployment/dep-nginx --to-revision=2 -n ns-rlaurens : Rollback d'une version erronée.

4. Services (Réseau)

  • ClusterIP : Type par défaut. Expose le service sur une IP interne (ex: Backend de base de données).
  • NodePort : Expose le service vers l'extérieur (ex: Frontend web).
  • kubectl port-forward svc/svc-nodeport-dep-app-guestbook 9999:80 -n ns-rlaurens : Transfert de port pour accès local.
